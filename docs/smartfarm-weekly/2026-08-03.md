1. 자율주행 파트 (김윤회 · 최현빈)
작업자를 따라다니는 무인대차가 안정적으로 사람을 추종하면서 장애물을 피하고, 자기 위치를 정확히 파악하도록 만드는 작업을 진행했습니다. 인지 기능과 주행 판단 기능의 역할을 나누어, 사람을 놓치지 않으면서 장애물이 있으면 우회하고 없으면 바로 따라가는 경로계획 기능을 처음으로 구현하였고, 개발자가 아니어도 화면으로 경로 선택 과정을 확인할 수 있는 시각화 도구도 마련했습니다. 또한 계산 방식을 개선해 **장애물 회피 계산 속도를 실시간 처리 기준 안으로 크게 앞당겼습니다.**

장애물을 인식하고 기억하는 지도 처리 방식도 전면적으로 다시 설계했습니다. 순간적인 오류를 장애물로 착각하지 않으면서도 실제 있는 장애물은 놓치지 않도록, 카메라가 실제로 보는 범위만 반영하고 오래된 기록에 무작정 의존하지 않는 방식으로 바꾸었으며, 처리 속도와 메모리 사용량도 함께 개선했습니다. 아울러 접촉 전에 미리 속도를 줄이는 초음파 센서 기반 감속 기능을 새로 추가해 안전장치를 한 겹 더 확보했습니다.

실제 차량 주행 기록을 분석해 **근접 시 좌우로 흔들리는 현상, 출발할 때 방향이 틀어지는 현상, 장애물 회피 중 접촉하는 현상의 원인을 각각 밝혀내고 수정하였습니다.** 이 과정에서 거리 카메라를 다시 장착하며 위치와 각도를 정밀하게 재조정했고, 회피할 때 조향이 충분히 되지 않아 접촉이 발생하던 문제도 해결해 회피 성능을 크게 끌어올렸습니다. 정면에 장애물이 없는데도 경로가 생성되지 않던 결함도 원인을 찾아 해결하였습니다. 코너를 부드럽게 도는 기능은 개발에 착수한 단계이며 아직 실차 검증 전입니다. 이 밖에 자동화 규칙 설정 조건을 완화하는 관련 시스템 개선도 진행했습니다. 다만 주 후반 초음파 센서 전장 작업 이후 좌우 모터 출력에 이상이 발견되어 원인 파악 작업이 진행 중입니다.

2. 스마트팜 제어 파트 (김희승)
센서 데이터를 PLC를 거쳐 받아오던 기존 방식 대신, **라즈베리파이가 센서노드와 직접 통신하는 방식으로 전환하기로 결정하였습니다.** 제어 기능은 기존 검증된 방식을 그대로 유지하고, 센서 수집 경로만 개선해 구조를 단순화하는 방향입니다.

> 참고 — Modbus RTU란?
> 여러 장비가 하나의 통신선을 함께 쓰면서 순서대로 묻고 답하는 방식의 통신 규격입니다. 여러 사람이 무전기 하나로 순서를 지켜 대화하는 것과 비슷하며, 센서 값을 읽거나 설정을 바꿀 때 사용됩니다.

관수 라인 실험에서는 **잔량 회수 효율과 작업 시간이 서로 상충하는 관계임을 확인**하였고, 라인 길이가 길어질수록 분사 품질이 떨어지는 경향도 함께 확인했습니다. 현장 출장에서는 연못펌프 전원 설비를 설치하고 라인 막힘 확인용 밸브를 설치했으며, 점검 과정에서 온도센서와 통신 모듈 다수의 불량을 확인했습니다. 저항식 토양습도센서는 정확도와 정밀도가 낮아 정식 운영에는 적합하지 않은 것으로 결론지었습니다. 잔류 농약 세척 실험에서는 염료를 이용해 세척 정도를 눈으로 확인해보았으나, 세척에 필요한 물량과 기준을 아직 정량화하지 못해 다음 실험에서는 식용색소를 이용해 기준을 세울 예정입니다.

3. 이번 주 계획 (2026년 8월 3일 ~ 8월 7일)

자율주행 파트는 회피 시 회전을 우선하는 감속 기능과 근접 추종 안정화 기능을 실차에서 다시 검증하고, **통신이 끊겼을 때 무인대차가 안전하게 멈추는 기능을 점검할 계획입니다.** 아울러 이번 주 발생한 모터 출력 이상의 원인을 확인하고, 실외 주행 시험과 코너 주행 성능 고도화도 함께 진행할 예정입니다.

스마트팜 제어 파트는 액체 비료 등을 정밀하게 투입하는 **도징펌프 방식의 도입을 위한 자료조사와 설계 논의를 진행**하고, 센서노드 펌웨어와 관련 문서 정리, 센서노드용 회로기판 2차 설계를 진행할 예정입니다. 아울러 라즈베리파이 서버의 모드버스 통신 기능 검토도 이어갈 계획입니다.
