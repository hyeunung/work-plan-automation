1. 무인대차 파트 (김윤회 · 최현빈)
무인대차 파트는 지난 한 주간 영남대 수질 센서 모니터링 시스템의 수집·관리 구조를 정비하는 데 집중했습니다. 먼저 현장 보드가 측정한 수질 센서 4종 값을 랩탑으로 모아 서버에 올리는 **BLE 게이트웨이 프로그램**을 새로 구현해, 로그인부터 업로드까지 전 과정을 테스트로 검증했습니다. 측정값 저장 방식도 센서별로 나뉘어 있던 구조에서 한 시점의 여러 센서값을 하나로 묶어 저장하는 방식으로 바꾸고, 화면에서는 한 그래프 안에서 여러 장치·여러 센서값을 동시에 비교하고 마우스를 올리면 값을 바로 확인할 수 있도록 개선했습니다. 또한 장비를 특정 프로젝트가 아니라 **조직 단위로 공유**하는 구조로 전환하고, 프로젝트를 대기·진행·일시정지·종료 단계로 관리하며 실제로 가동된 기간만 통계·알람에 반영되도록 만들었습니다. 조회한 기간·장치 조건 그대로 CSV·엑셀 파일로 내려받는 기능과 지도에서 장치 위치를 확인하는 기능도 함께 구현했습니다. 아울러 외부 서버 없이 현장에 직접 납품하는 **온프레미스 운영 패키지**의 구성 범위와 인수 조건을 정리했습니다.

> 참고 — 온프레미스란?
> 외부 인터넷 서버 없이, 현장 컴퓨터에 프로그램을 직접 설치해 운영하는 방식입니다. 인터넷이 끊겨도 현장에서 바로 데이터를 모으고 확인할 수 있습니다.

2. 스마트팜 제어 파트 (김희승)
스마트팜 제어 파트는 온실 관수·관비 자동화를 맡은 PLC 제어 로직을 구조적으로 다시 설계하고 구현하는 작업을 진행했습니다. 69개에 달하는 모든 장치를 하나의 공통 틀로 관리할 수 있도록 **장치 관리 구조를 확정**하고, 이를 바탕으로 영양제 자동 관비 로직(약 60개 렁 규모)을 실제로 구현해 두 차례 검증하며 오류를 바로잡았습니다. 관수 로직에도 일시정지·재개 기능을 적용했고, 수위 센서와 모드버스 통신 로직의 민감도를 개선해 오작동 가능성을 줄였습니다. 아울러 물탱크·영양제탱크의 **수위 한계값을 확정**하고, 값과 상태를 분리해 원인을 한곳에서 추적할 수 있는 구조로 탱크 감시 로직을 정리했습니다. 영남대와 진행하는 수질 센서 시연을 위해 센서 측정값을 실시간 수신·저장·조회·내보내기까지 처리하는 **1차 시연 설계와 전송 데이터 규격**도 함께 정리했습니다.

3. 이번 주 계획 (2026년 10월 5일 ~ 10월 9일)

무인대차 파트는 영남대 수질 센서 모니터링 시스템의 납품을 앞두고 **운영·설치 매뉴얼을 포함한 납품 문서 작성**을 진행할 예정입니다. 아울러 센서 측정값을 실제 값으로 변환하는 보정(Calibration) 테이블과 적용 로직을 설계하고, 현재까지 진행 상황을 정리해 전달할 예정입니다.

스마트팜 제어 파트 역시 같은 수질 센서 모니터링 시스템 납품을 지원해 **센서 보정(Calibration) 로직 설계**에 참여하고, 현재까지의 제어·설계 진행 사항을 전달할 예정입니다.
