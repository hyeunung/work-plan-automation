스마트팜 주간업무 보고
보고기간: 2026년 10월 12일 ~ 10월 16일

1. 무인대차 파트 (김윤회 · 최현빈)
지난주에는 영남대 수질 센서 모니터링 시스템 개발을 중심으로 진행하였습니다. pH·TDS·용존산소(DO) 센서의 보정값을 서버에 반영하고 원본 측정값과 보정값을 함께 저장하도록 구조를 개편하여 **측정 데이터의 신뢰도를 높였습니다**. 데모용으로만 쓰이던 장치 상세 화면을 실제 등록 장치와 조직 공유 장치에서도 볼 수 있도록 연동하였고, 하루 단위 수질 추이를 자동으로 집계·저장하는 기능을 구축하였습니다. 현장에서 PC로도 모니터링·관리가 가능하도록 **데스크톱 작업실 기능을 확장**하였고, 측정값 내보내기(CSV/엑셀)에 보정 계수와 한국시간 기준 시각을 함께 담아 분석 편의성을 높였습니다. 아울러 알림 체계를 프로젝트 단위에서 조직 단위로 전환해 실제 측정값을 기준으로 알림이 울리도록 개선하였고, 참여자·장치 권한 구조를 정리하였습니다. NAS 설치부터 장애 복구까지 안내하는 운영 매뉴얼도 작성하여 **향후 현장 서버 구축 준비를 마쳤습니다**.

2. 스마트팜 제어 파트 (김희승)
지난주에는 영남대 피드백을 반영해 **1차 시연안을 확정**하였고, 관수·관비·미세살수 자동화 로직과 스케줄링, HMI 화면 테스트를 모두 완료하였습니다. 밸브별 실제 유량을 측정한 결과 유량계가 실제값보다 7~15% 적게 측정됨을 확인하였고, 정식 보정계수가 확정되기 전까지 사용할 운용 기준을 마련하였습니다.

> 참고 — TDS·pH·DO 센서란?
> 각각 물속 영양분 농도(TDS), 산성도(pH), 녹아있는 산소량(DO)을 재는 센서입니다. 사람이 혈압·체온을 재듯, 작물에 공급되는 물과 양액의 상태를 숫자로 확인하는 역할을 합니다.

수질센서 PCB 조립을 진행하였고, 세 센서의 측정 원리와 교정 방식을 정리해 **교정 설계 문서를 완성**하였습니다. 이를 바탕으로 수질 측정 장치(WQM)의 펌웨어 구조 설계에 착수하여, 센서값을 측정해 서버로 전송하는 기본 골격을 구현하였습니다.

3. 이번 주 계획 (2026년 10월 19일 ~ 10월 23일)

무인대차 파트 (김윤회 · 최현빈)
이번 주에는 수질 센서 모니터링 시스템의 **WAS(운영 서버) 설치**를 진행하고, 전체 서비스가 실제 환경에서 정상 동작하는지 통합 테스트를 수행할 예정입니다.

> 참고 — WAS란?
> 웹 화면과 데이터베이스를 이어 실제 서비스를 돌려 주는 운영용 컴퓨터(서버)를 말합니다.

통합 테스트 과정에서 드러나는 문제를 바탕으로 **API 수정**도 함께 진행할 계획입니다.

스마트팜 제어 파트 (김희승)
이번 주에는 밸브별 유량 보정계수를 확정하여 관수 루틴에 반영하고, 센서 raw값 측정을 통해 교정식의 정확도를 검증할 예정입니다. 아울러 수질 측정 장치(WQM) 펌웨어의 테스트모드와 저장 기능 구현을 이어가며 **1차 시연 준비**를 계속 진행할 예정입니다.
