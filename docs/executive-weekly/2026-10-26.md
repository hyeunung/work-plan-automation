스마트팜·영남대 주간업무 보고
보고기간: 2026년 10월 19일 ~ 10월 23일

1. 영남대 수질센서 모니터링 시스템 (김희승 · 최현빈 · 정승후)
수질센서 펌웨어와 서버 연동을 진행해 **보드에서 측정한 데이터를 서버로 처음 전송하는 데 성공**하였고, Wi-Fi 송신 출력을 15dBm으로 조정해 연결 안정성을 확보하였습니다. 2차 보드의 소모전력을 분석해 배터리 운용 방향을 정리하였고, GPS 모듈은 실외 시험에서 위치 수신이 정상임을 확인하였습니다. 서버 쪽에서는 측정 업로드 안전성과 비밀번호 보안을 강화하고 기존 테스트 실패 65건을 모두 해소하였으며, **B2B 운영 인계서를 33쪽 분량으로 전면 개편**하였습니다. 아울러 온프레미스 서버 배포 구성을 정리하고 모바일 앱 1차 기능 범위와 화면 시안을 설계하였으며, 2차 보드의 센서 모듈 내재화 회로 설계도 계속 진행하였습니다.

2. 영남대 혈당 모니터링 앱(글루하루) (김윤회)
글루하루 서버의 불필요한 서비스를 꺼 메모리 사용을 줄이고, 부하 시험을 통해 **100명 동시 사용에도 메모리 여유가 있음을 확인**하였습니다. 영남대 현장에 네트워크와 NAS·맥 스튜디오 서버 구성을 시작하였고, 연구실 서버 설치 안내서와 현장 작업 절차를 정비하였습니다. 영남대에 시제품 진행 상황을 **중간 보고**하였고, 현장 접속 시험용 앱 두 종류를 빌드해 전달 준비를 마쳤습니다. 앱 쪽에서는 새 디자인(10안)을 반영한 v2 앱의 주요 화면 흐름을 구현하고, 디자인 시안 정리본을 영남대 연구실에 전달하였습니다.

3. HW 설계 자동화(AI) (김희승)
AI를 활용한 하드웨어 설계 자동화 방법을 시험하여, **알티움 설계 데이터를 KiCad·Flux로 변환해 회로도와 보드를 그대로 재현하는 경로를 완성**하였습니다. 검사 과정에서 오류를 다수 찾아 수정하여 설계 오류 지적 27건을 1건으로, 배치·배선 규칙 위반 31건을 1건으로 줄였습니다.

> 참고 — ERC·DRC란?
> 회로도와 기판 설계에 연결 실수나 설계 규칙 위반이 있는지 자동으로 검사해 주는 전자회로 검증 기능입니다.

이후 자동 배치·배선 결과의 품질을 판단할 기준이 없다는 점을 확인하고, 1차 보드 전체를 가져와 기준을 세우는 시험을 준비 중입니다.

4. 솔루션 1차 프로토타입 (김희승)
스마트팜 솔루션 1차 프로토타입에서는 영양제 관비 설정 로직을 추가하고 **HMI 제어 화면을 확장**하였으며, 사용자 매뉴얼 작성을 진행하였습니다.

5. 이번 주 계획 (2026년 10월 26일 ~ 10월 30일)
영남대 수질센서 모니터링 시스템은 펌웨어 네트워크 기능을 마저 점검하고 실서버 연동과 현장 Wi-Fi 출력 재점검을 진행할 예정입니다. 모바일 앱은 요구사항 정의와 화면 시안, API 확장 검토를 진행하고 웹 애플리케이션 요구사항 대응도 이어갈 예정이며, 2차 보드는 센서 모듈 내재화 회로도를 마무리하고 **부품 라이브러리 정리와 PCB 아트웍 작업에 착수**할 예정입니다.
영남대 혈당 모니터링 앱은 NAS 서버 재적용과 학교 고정 IP·외부 공개 승인을 확인해 현장 접속 시험을 진행하고, v2 앱 화면을 실제 휴대폰으로 점검한 뒤 iOS·Android 시험 배포를 진행할 예정입니다. 디자인 시안에 대한 **연구실 검토 의견 확인**도 함께 진행할 예정입니다.
HW 설계 자동화는 1차 보드 전체를 대상으로 배치·배선 시험을 진행해 품질 판단 기준을 세우는 작업을 이어갈 예정입니다.
솔루션 1차 프로토타입은 별도 계획이 확정되지 않았습니다.
