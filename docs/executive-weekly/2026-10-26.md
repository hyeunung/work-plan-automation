스마트팜·영남대 주간업무 보고
보고기간: 2026년 10월 19일 ~ 10월 23일

1. 영남대 수질센서 모니터링 시스템 (김희승 · 최현빈 · 정승후)
센서 보드 1단계 개발을 마무리하고 **처음으로 보드가 서버와 무선 통신에 성공**하였으며, GPS 모듈도 실외 테스트에서 위치 측정이 정상 확인되었습니다. 2차 보드는 저전력 모드를 적용해 소비 전력을 315mA에서 27mA 수준으로 크게 줄여 배터리 운용 가능성을 확인했습니다.
서버 쪽에서는 비밀번호 보안 수준을 강화하고 **테스트 실패 65건을 모두 해소**하였으며, 온프레미스 배포 구조를 정비하고 B2B 운영 인계서를 새로 정리했습니다. 아울러 모바일 앱의 1차 기능 범위와 화면 구성안을 수립하였습니다.

2. 영남대 혈당 모니터링 앱(글루하루) (김윤회)
연구실 서버의 메모리 사용량을 점검하고 영남대 현장 설치를 진행했습니다. 불필요한 서버 기능을 정리해 **최대 부하 상황에서도 메모리 사용을 1.14GB 수준으로 유지**함을 확인했고, 서버 역할을 맥 스튜디오(앱)와 NAS(DB)로 나눠 구성했으나 현장 네트워크 연결 과정에서 일부 접속 오류가 발생해 확인이 필요한 상태입니다.
앱 개발에서는 새 디자인(v2) 주요 화면 구현을 마치고 현장 접속 시험용 앱을 제작해 전달했으며, 영남대에는 중간 보고와 디자인 시안을 전달해 검토를 요청했습니다.

3. HW 설계 자동화(AI) (김희승)
자체 연구과제인 HW 설계 자동화는 AI가 회로도부터 아트웍까지 설계를 보조하는 체계를 시험하는 단계입니다. 알티움 설계를 KiCad와 Flux로 변환하는 방법을 검증해 1차 보드 변환에 성공하였고, 검증 과정에서 드러난 오류를 대부분 해소하며 품질 검사 체계를 구축했습니다.
다만 Flux로 만든 배치·배선 결과를 평가할 품질 기준이 아직 없다는 점을 확인해, 1차 보드 전체를 직접 돌려보며 기준을 세우는 작업을 진행 중입니다.

4. 솔루션 1차 프로토타입 (김희승)
스마트팜 솔루션 1차 프로토타입은 영양제 관수비 설정 로직을 추가하고 HMI 화면을 보완했으며, 사용자 매뉴얼 작성을 진행했습니다.

5. 이번 주 계획 (2026년 10월 26일 ~ 10월 30일)
영남대 수질센서 모니터링 시스템은 네트워크 통신 검증을 마무리하고 2차 보드의 저전력 설계안을 확정할 예정이며, 모바일 애플리케이션 요구사항 정의와 화면 시안 작업, 센서 내재화 보드의 PCB 아트웍 착수를 이어갈 예정입니다.

영남대 혈당 모니터링 앱(글루하루)은 연구실 서버의 현장 적용을 이어가며 고정 IP와 외부 공개 승인을 확인하고 현장 접속 시험을 진행할 예정이며, v2 디자인 화면을 실제 기기에서 확인하고 iOS·안드로이드 테스트 버전을 배포할 예정입니다.

HW 설계 자동화는 1차 보드를 활용한 품질 기준 수립 테스트를 완료하고, 부품 선정 기준과 아트웍 배치·배선 비교 시험을 이어갈 예정입니다.

솔루션 1차 프로토타입은 별도 계획이 확정되지 않았습니다.
