스마트팜·영남대 주간업무 보고
보고기간: 2026년 10월 26일 ~ 10월 30일

1. 영남대 수질센서 모니터링 시스템 (김희승 · 최현빈 · 정승후)
모바일 앱은 화면 체계를 재설계해 실제 서버 API와 연동되는 단계까지 구현을 마쳤고, 조회 필터·알림·인증 구조도 함께 안정화했습니다. 하드웨어는 회로 설계를 최종 확정해 **부품 188개 연결을 오류 없이 검증**했고, 센서 회로를 내재화했음에도 보드 면적을 절반 이하로 줄였습니다. 아트웍실 검토에서 배선과 절연 간격이 대부분 기준대로 완성된 것을 확인했고, pH 측정 정확도 보완 사항도 함께 점검했습니다.

2. HW 설계 자동화(AI) (김희승)
AI 기반 하드웨어 설계 자동화 검증에서, 기존 보드와 비교하던 방식 대신 설계 원리를 데이터로 정리하고 AI가 계획을 세우면 도구는 실행만 담당하는 방식으로 전환했습니다. 이번 주 시험에 **약 400 ACU**를 투입했으며, 기판 기준면이 세 조각으로 갈라지는 문제를 확인해 다음 시험에서 보완하기로 했습니다. 작업 자동화 템플릿도 완성해 배포까지 마쳤습니다.

3. 시스템 리빌딩 (최현빈)
스마트팜 웹 메뉴에 수동 제어·자동운전·관수 등 사용법을 바로 확인할 수 있는 사용가이드를 추가했습니다. 메시지 큐 통신이 장시간 끊긴 뒤 복구되지 않던 문제의 원인을 찾아, 끊기면 자동으로 정리하고 재접속하도록 구조를 개선했습니다.

4. 영남대 혈당 모니터링 앱(글루하루) (김윤회)
글루하루 v2 개발 빌드를 실제 휴대폰에 설치해 확인했고, 첫 로그인 후 앱이 멈추던 오류와 음성 기록 재입력 불편을 해소했습니다. 실시간 화면을 현재 혈당과 최근 흐름 중심으로 단순화한 개선안을 본 앱에 반영하고, 연구용 데이터 추출과 서버 구성 변경 사항도 함께 통합했습니다.

5. 무인대차 1차 프로토타입 (김윤회)
위치 보정 신호 서버가 반복 접속으로 계정이 차단되던 문제의 원인을 찾아, 위치 정보 확보 뒤에만 로그인하고 접속 빈도를 제한해 **차단 문제를 해소**했습니다. 모드 전환 시에도 제한 기록이 유지되도록 보완했으며, 실차 확인은 아직 진행 전입니다.

6. 솔루션 1차 프로토타입 (김희승)
PLC 제어 로직 전체를 설계 명세서와 하나씩 대조해 점검했고, 확인된 항목은 모두 정상 동작함을 확인했습니다. 발견된 문제를 반영해 관수·관비 관련 로직 일부를 수정하고 설계 문서를 최신화했습니다.

7. 이번 주 계획 (2026년 11월 2일 ~ 11월 6일)
영남대 수질센서 모니터링 시스템은 아트웍실 수정 결과를 반영해 **보드 설계를 최종 완성**하고, 모바일 앱은 실제 API 연동과 알림 기능 검증을 이어갈 예정입니다.

HW 설계 자동화(AI)는 기준면 분할 문제를 보완한 재시험을 진행하고, 결과를 바탕으로 아트웍 담당자 평가로 넘어갈 예정입니다.

시스템 리빌딩은 사용가이드 기능의 빌드·접근성 확인 후 커밋을 마무리하고, 메시지 큐 복구 로직의 현장 적용 검증을 이어갈 예정입니다.

영남대 혈당 모니터링 앱(글루하루)은 v2 개선 사항을 실제 휴대폰으로 최종 확인하고, 영남대 서버 접속 설정과 외부 공개 승인 확인, 디자인 시안 전달을 진행할 예정입니다.

무인대차 1차 프로토타입은 접속 유지 수정본을 기준으로 **주차장 실차 시험**을 진행하고, 휴대폰 조작 화면과 추종 기능 연동 시험을 이어갈 예정입니다.

솔루션 1차 프로토타입은 별도 계획이 확정되지 않았습니다.
