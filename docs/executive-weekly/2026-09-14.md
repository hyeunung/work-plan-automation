스마트팜 주간업무 보고
보고기간: 2026년 9월 7일 ~ 9월 11일

1. 무인대차 파트 (김윤회 · 최현빈)
무인대차의 위치·동작 정확도를 판정하는 검사장비 자체의 신뢰성을 검증하는 작업을 진행했습니다. 여러 보드 간 신호 도달시간과 반복 계측을 정밀 비교해 **측정 성능 검증 성적서(20쪽, 최종 개정 3판)를 완성**했고, 외부 계측 장비와 검사장비가 같은 신호를 얼마나 일치되게 기록하는지 직접 대조하는 방법도 새로 구현해 실측 근거를 확보했습니다. 다만 일부 짧은 이상 신호 등은 원인 확인이 남아 있어 결과를 보수적으로 관리하고 있습니다.

실제 위치 인식 정확도를 높이기 위해 **위성항법(GPS/RTK) 실물 수신 시험**을 진행해 보정 신호 수신 상태를 확인했고, 이동 중에는 위치 표시가 정상으로 보여도 실제 보정이 지연된 경우가 있다는 점을 확인해 이를 구분하는 기준을 마련했습니다. 이 위치 정보를 무인대차의 실제 방향·이동 추정과 결합하는 작업도 함께 진행했습니다.

휴대폰 하나로 무인대차 화면에 접속해 시스템을 켜고 끄는 원격 운용 환경을 구축했고, 위성지도 위에 경로를 그리면 그대로 주행하다가 위치 이상이나 장애물 발생 시 자동으로 멈추는 기능을 모의환경에서 검증했습니다. 전원을 켠 뒤 별도로 리셋해야 통신이 연결되던 문제도 해결했으며, 주행 시험 결과를 회차별로 기록해 오차를 보고서로 확인하는 기능과 부품 현황 정리도 함께 진행했습니다.

한편 주행 중 반복적으로 발생하던 **덜컹거림의 주요 원인이 위치 신호 지연 시 제동 후 새 경로로 급가속하는 구간이라는 점을 실측 데이터로 규명**했고, 사람 추종·근거리 장애물 회피 판단 구조도 점검해 개선 방향을 정리했습니다. 이와 함께 자동화 루틴의 실행·기록·통신 체계 전반을 정비해, 수동 루틴 실행 중에도 다른 명령을 즉시 처리하도록 개선하고 **실행 상태 저장·전달 방식을 새 표준(v4)으로 통일**해 현장 장비와 화면 간 상태 불일치, 종료 처리 누락 문제를 바로잡았습니다. 화면에서도 실행 중 단계를 더 명확하게 표시하도록 개선했습니다.

2. 스마트팜 제어 파트 (김희승)
자동화 루틴의 강제종료·모니터링 방식을 놓고 개선 방향을 논의했습니다. 트리거 시간 편집이 반영되지 않아 정량펌프가 중복 작동하던 버그 원인을 확인했고, **자동화 종료 시 관련 접점을 모두 차단하는 방식과 실행 단계를 화면에서 밝게 표시하는 모니터링 기능 도입**을 결정했습니다. 다만 배관·펌프 등 공용 장비의 안전정지 체계는 추후 단계적으로 설계하기로 했습니다.

센서노드 통신 불량 문제를 해결해 초음파센서 추가 시 발생하던 데이터 오류를 바로잡았고, 영양제·농약탱크 초음파센서는 벽면 간섭으로 잘못 측정되던 위치를 옮겨 정상 측정을 확인했습니다. 이 과정에서 **영양제탱크의 실제 부피와 센서 거리값을 정밀 대조해 4구간 직선 모델을 확정**했고, 이를 반영한 PLC 프로그램 작성과 테스트를 완료했습니다.

**유량계 적산 프로그램도 작성을 완료**했습니다. 기존 5톤 물탱크 수위 판정 방식을 초음파 센서 기반으로 전환하고 유량계 신호를 적산해 사용량을 계산하는 로직을 새로 구현했으며, 현장 테스트는 이번 주로 예정되어 있습니다. 이 외에 연못·창고 쪽 지지대와 고추대, 도징펌프 거치대 설치, 대차바퀴 수리 등 현장 설비 작업도 함께 마쳤습니다.

3. 이번 주 계획 (2026년 9월 14일 ~ 9월 18일)

무인대차 파트 (김윤회 · 최현빈)
목요일 1일 출장이 예정되어 있으며, 현장에서는 임시 PLC 기반 유량계 설치와 측정 검증, 잔량펌프용 물탱크 설치를 진행하고 센서노드(F767) 펌웨어의 구조 개선과 기능 보완도 병행할 예정입니다. 아울러 자동화 시스템 구조 재정비를 이어가 **웹 화면의 자동화 루틴 작성 편의성 개선과 신규 통신 프로토콜(v4) 배포**를 진행하고, 실제 장비 없이 전체 흐름을 점검할 수 있는 모의 PLC 환경을 구축해 통합 테스트를 수행할 예정입니다.

스마트팜 제어 파트 (김희승)
마찬가지로 목요일 1일 출장을 통해 유량계를 설치·운영하며 측정값을 검증하고 잔량펌프 물탱크 설치를 진행할 예정입니다. 또한 **센서노드(F767) 펌웨어의 리팩토링과 기능 개선**을 함께 추진할 예정입니다.
