## 📝 10월 06일 (화요일) 업무 요약 브리핑

> 각 팀원들의 금일 업무 목적 및 진행 의미 요약입니다.

### 👤 김윤회 님
* **EtherCAT 마스터 구동 감독·메일박스 기본값 확정과 크기 검사 정비**
  - *목적*: 코드 크기가 늘어나는 것을 감지하고 시운전 절차를 문서로 남기기 위해서다.
  - *진행 의미*: 크기 증가를 자동으로 알 수 있고 시운전 시 확인할 항목이 정리됐다.
* **STM32H7S7 포트 작성과 응답 지연 시험·마스터 결함 2건 수정**
  - *목적*: 늦게 도착한 응답이 잘못 처리되는 문제를 막기 위해서다.
  - *진행 의미*: 지연이 있는 환경에서 오응답 가능성이 줄었다. OP 단계 링크 끊김의 AL_STATE 기록은 후속으로 남았다.
* **EtherCAT ETG 규격 대조 완료와 대조 결과 반영 수정**
  - *목적*: 대조에서 나온 오류와 검증 리뷰 지적을 코어와 시뮬레이터에 반영하기 위해서다.
  - *진행 의미*: 링크 끊김 원인이 정확히 기록되고 규격 대조 지적이 코드에 반영됐다.
* **아이폰에서 입력 창이 열려 있을 때 저혈당 경고가 안 보이던 문제 수정**
  - *목적*: 아이폰에서 기록 입력 창, 채혈 입력 창, 위치 동의 창이 열려 있으면 저혈당 경고 화면이 뜨지 않고 소리·진동만 울리던 문제를 해결한다. 창을 닫은 뒤에도 경고 화면이 나타나지 않았다.
  - *진행 의미*: 위험한 저혈당 상황에서 사용자가 경고 화면을 놓치지 않게 되었다.
* **센서 혈당값 계산을 제조사 방식으로 전환**
  - *목적*: 테스터 센서 하나가 부착 후 처음 3일 동안 공식 앱보다 18~22 mg/dL 낮게 표시되던 문제(82를 52로 표시)를 해결한다.
  - *진행 의미*: 앱 표시값이 공식 앱과 같아져 연구실 시연·테스트에서 값 차이로 인한 혼란이 줄어든다.
