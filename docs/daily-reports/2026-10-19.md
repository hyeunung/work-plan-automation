  - *상세*: 측정 업로드에서 누락된 serial 헤더가 500 오류를 만들고, 동일 이벤트의 동시 요청이 간헐적으로 409를 반환하던 문제를 수정함. 입력 오류를 명확히 구분하고 같은 장치의 업로드를 트랜잭션 단위로 직렬화해 중복 저장과 알람 중복 생성을 방지함.
* **비밀번호 페퍼·scrypt 비용 강화 및 점진적 해시 전환**
  - *상세*: DB의 비밀번호 해시가 유출됐을 때 오프라인 추측 공격에 대한 방어를 높이기 위해 페퍼 기반 사전 해시와 OWASP 권장 수준의 scrypt 비용을 적용함. 기존 계정은 로그인 가능하게 유지하고 로그인 성공 시 새 형식으로 자동 전환하도록 구현함.
* **서버 테스트 계약 정비 및 65건 실패 해소**
  - *상세*: 현행 API 계약과 맞지 않던 서버 테스트를 정비해 기존 실패 65건을 모두 해소함. 구 API 경로를 호출하던 61건과 구성원 응답 형식이 달랐던 4건을 중심으로 원인을 분류하고 테스트 기대값과 픽스처를 최신 동작에 맞춤.
