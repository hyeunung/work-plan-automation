  - *개요*: 연속 depth 프레임에서 OccupancyGrid 값이 유지되는 셀과 변경되는 셀을 구분하기 위한 Python 전용 실험 로직을 작업 중임.
* **base_link와 OccupancyGrid 원점 Marker 추가**
  - *개요*: 카메라 바로 아래의 관측 불가 영역과 grid 경계 때문에 RViz2에서 로봇 위치 및 원점을 구분하기 어려운 문제를 보완함.
* **Python 노드 단계별 처리시간 계측 및 Raycast 병목 완화**
  - *개요*: grid 처리 속도가 약 4Hz로 제한되던 원인을 확인하기 위해 Python 노드에 단계별 성능 계측을 추가하고, 현재 출력에 사용되지 않는 free raycast를 임시 비활성화함.
* **Depth 입력 설정 정리 및 카메라 좌표계 점검**
  - *개요*: launch 실행 시 전달하던 depth Image·CameraInfo 토픽을 YAML 설정으로 이동하고, 카메라 높이와 base_link 기준 지면 계산에 사용되는 TF 관계를 점검함.
* **Rolling 누적 Grid를 base_link 기준 최신 프레임 Grid로 전환**
  - *개요*: odom 좌표에 과거 voxel을 누적하던 rolling grid 구조를 제거하고, 각 depth 프레임의 관측만 사용하는 base_link 기준 2.5D Local OccupancyGrid로 전환함.
