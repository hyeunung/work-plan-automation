  - *진행 의미*: 경로가 왜 직선 또는 우회로 선택됐는지 비개발자와 팀원이 함께 확인할 수 있는 검증 화면의 기반을 마련함.
* **경로계획 처리속도 개선**
  - *목적*: 장애물 회피 계산을 5Hz 운용 주기 안에 안정적으로 끝내고 센서 입력 처리가 밀리지 않게 하기 위함.
  - *진행 의미*: 일반 직선 추종과 대표 우회 상황에서 경로계획이 다음 입력을 막을 가능성을 낮춤.
* **장애물 누적지도 안전성 보강**
  - *목적*: 순간 노이즈는 장애물로 확정하지 않으면서, 작업자 주변의 실제 가림물과 장애물을 잘못 지우지 않기 위함.
  - *진행 의미*: 사람을 따라가기 위해 주변 장애물을 지워 버리는 위험을 없애고, 관측 신뢰도와 보수적 정지를 함께 유지하는 기반을 확보.

### 👤 최현빈 님
* **IF 액션의 Else 조건 필수 길이 제한 제거**
  - *개요*: 자동화 규칙 등록 시 else 액션 배열이 존재하면 무조건 한 개 이상의 항목을 요구하던 DTO 검증 조건을 완화함.
* **RViz2용 높이 Grid 토픽 발행 추가**
  - *개요*: 2D OccupancyGrid만으로 확인하기 어려운 지면과 장애물의 Z축 볼륨을 RViz2에서 확인할 수 있도록 디버그용 2.5D 높이 토픽을 추가함.
* **시간 기반 Decay 제거 및 시야 밖 공간 기억 유지**
  - *개요*: 전체 grid를 프레임마다 초기화하지 않고 현재 depth 시야에 포함된 영역만 갱신하며, 시야 밖의 과거 관측은 계속 기억하도록 rolling voxel 정책을 변경함.
* **Odometry 기준을 camera_link에서 base_link로 변경**
  - *개요*: 최초 설계의 odom → camera_link 전제를 실제 차량 TF 계약에 맞는 odom → base_link 구조로 변경하고, rolling grid 중심을 카메라에서 차체 중심으로 이동함.
* **Freespace Grid와 경로계획 책임 재정의**
  - *개요*: 기존 작업자 직접 추격 및 corridor 기반 회피 구조와 2.5D grid 기반 A* 구조를 비교하고, 회의 결과에 따라 freespace_grid의 책임 범위를 환경 표현으로 한정함.
