## 📝 10월 01일 (목요일) 업무 요약 브리핑

> 각 팀원들의 금일 업무 목적 및 진행 의미 요약입니다.

### 👤 김윤회 님
* **식사 사진 촬영·업로드 실기기 확인**
  - *목적*: 9/29 영남대 회신을 반영해 넣은 식사 사진 기록 기능이 실제 휴대폰에서 동작하는지 확인한다.
  - *진행 의미*: 회신 반영 항목 중 남은 확인이 보안 저장소, 로컬 저장소 버전 올림, 연구실 서버 이전 리허설 세 가지로 줄었다.
* **앱 재실행 시 센서 연결 끊김·혈당값 중복 수신 수정**
  - *목적*: 앱을 다시 열 때마다 실시간 화면이 '연결 중'으로 바뀌는 문제를 없앤다.
  - *진행 의미*: 참여자가 앱을 자주 여닫아도 실시간 혈당 표시가 끊기지 않는다.
* **안드로이드 Play 제출 거절 해결·시험 배포 업데이트 조건 정비**
  - *목적*: 배포 설정만 바꿨는데 기존 시험 빌드가 앱 업데이트를 받지 못하는 문제를 막는다.
  - *진행 의미*: 아이폰·안드로이드 모두 시험 배포 경로가 열렸다.

### 👤 최현빈 님
* **Workspace 조회 조건 연동 CSV·Excel 추출 UI 구현**
  - *상세*: 프로젝트 Workspace에서 조회에 적용한 기간·장치·측정 항목을 그대로 사용해 CSV와 Excel(.xlsx) 파일을 생성·다운로드할 수 있는 추출 UI를 구현했다. 화면의 50건 페이지 제한과 무관하게 선택 범위 전체를 서버 추출 작업으로 처리하도록 연결했다.
* **카카오맵 위·경도 검색과 마커 연동**
  - *상세*: 기존 지도 컴포넌트를 카카오맵 JavaScript SDK(소프트웨어 개발 도구) 기반으로 정리하고, 사용자가 입력한 위도·경도로 지도를 이동해 마커를 표시할 수 있도록 구현했다.
